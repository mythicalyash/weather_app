# Weather App 🌤️

A clean and minimalist weather application that provides real-time weather information for any location worldwide.

## Features

✨ **Real-time Weather Data** - Get current temperature, weather conditions, and location details  
🔍 **Location Search** - Search for any city or location globally  
📱 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices  
🎨 **Clean UI** - Minimalist teal/grey gradient design for better user experience  
⏰ **Time & Date Display** - Shows current time, day, and date for the searched location  

## Technologies Used

- **HTML5** - Structure and markup
- **CSS3** - Styling with gradients and responsive design
- **JavaScript (ES6)** - Dynamic functionality and API integration
- **Weather API** - Real-time weather data from [WeatherAPI.com](https://www.weatherapi.com/)

## Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/mythicalyash/weather_app.git
   cd weather_app
   ```

2. **Open the application**
   - Simply open `index.html` in your web browser
   - No build process or dependencies required!

## Usage

1. Enter a city name or location in the search box
2. Click the "Search" button
3. View the weather information including:
   - Current temperature
   - City name
   - Local time and date
   - Weather condition with icon

## API Reference

This app uses the [WeatherAPI.com](https://www.weatherapi.com/) free API to fetch weather data.

**Endpoint:** `https://api.weatherapi.com/v1/current.json`
